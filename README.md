# タッチ練習 — さわると音と光がかえってくるアプリ

画面をさわると、その場所から音と波紋がひろがります。
「さわった → 何かが起きた」という手ごたえを返すことに絞ったアプリです。

**https://eduwithdai.github.io/touch-practice/**

## つかいかた

1. 上のURLをひらく
2. 3つのなかから、その子に合ったモードをえらぶ
3. 画面のどこでもいいので、さわる

- **画面のどこをさわっても** — ポンと音が鳴り、さわった場所に色のついた波紋がひろがります
- **光る玉をさわると** — キラキラと上がっていく音とドラムが鳴り、玉がはじけて、まわりに8つの波紋がひろがります

光る玉は、開くと少ししてから画面のどこかに現れます。
さわってはじけると、1秒ほどで次の玉が別の場所に出てきます。
玉は16種類の絵文字と8色からランダムに選ばれるので、毎回ちがうものが出ます。

## モード

はじめの画面で3つからえらびます。**ちがうのは玉の大きさと動き方だけ**で、
音・波紋・数え方はどのモードでも同じです。

| | 玉の大きさ | 玉の動き |
|---|---|---|
| 🐢 **かんたん** | 直径360px（ふつうの2倍） | じっとしている |
| ⭐ **ふつう** | 直径180px | その場でふわふわ上下する |
| 🚀 **むずかしい** | 直径180px | 画面じゅうを動きまわり、はしではね返る |
| 👹 **おに**（かくれ） | 直径90px（ふつうの半分） | むずかしいの3倍の速さで動きまわる |

画面のせまい端末では、玉が画面からはみ出さないよう自動で小さくなります
（短いほうの辺の6割まで）。iPadなら「かんたん」は360pxのまま出ます。

### かくれモード「おに」

メニューには出しません。**はじめの画面のタイトル「タッチ れんしゅう」を、2秒以内に5回つづけてタップ**すると始まります。
玉が「ふつう」の半分の大きさ（直径90px）になり、速さは「むずかしい」の3倍（450px/秒）になります。

ボタンとして置くと子どもが選んでしまうので、どこにも表示していません。
5回に足りなかったり、間が2秒以上あいたりすると数えなおしになります。
きろくには「おに」として残ります。

**モードを変えるときは、左下の「メニュー」を1秒ほど押し続けます。**
子どもが偶然さわっても抜けないよう、長押しでないと反応しません。
メニューに戻ると、タッチ数とせいこう数は0に戻ります。

## 先生用

**右下にモード名と2つの数字**が出ます。子どもの気が散らないよう、うっすらとしか表示していません。

| | |
|---|---|
| **タッチ** | 画面にさわった回数。玉にさわれた分も含む、のべ回数です |
| **せいこう** | 光る玉にさわれた回数 |

「タッチ5・せいこう2」なら、5回さわったうち2回は玉をとらえられた、という読み方です。
玉にさわれたときは、両方の数字が1ずつ増えます。

画面上の数字は、メニューに戻ると0に戻ります。

### きろくを残す

**右下の「ほぞん」を1秒ほど押し続ける**と、そのときの成績が端末に残ります。
残るのは次の4つです。

| | |
|---|---|
| 日づけ | 押した日時（2026/9/12 14:03 の形） |
| レベル | かんたん / ふつう / むずかしい |
| タッチ | そのときのタッチ数 |
| せいこう | そのときのせいこう数 |

押すと「ほぞんしました」と出ます。**保存しても数字は0に戻りません**ので、
続けて練習してもう一度押せば、その時点の数字がもう1件増えます。

きろくを見るには、メニュー画面の下にある**「きろく ○けん」**を押します。
新しいものが上に並び、いっぱいになったら指でスクロールできます。

消すときも長押しです。

- **1件だけ消す** — その行の右はしにある「けす」を長押し
- **ぜんぶ消す** — 一覧の右下の「ぜんぶ消す」を長押し

消したものは元に戻せません。

## 使うときに気をつけること

- **音は最初にさわった瞬間から鳴ります。** ブラウザは、利用者が一度も操作していないページに音を出すことを許していません。開いた直後に無音でも故障ではないので、まず一度さわってみてください
- **音が出ないときは、本体の音量と消音スイッチを確かめてください。** とくにiPadは、消音にしているとこのアプリの音が鳴りません
- 玉は画面の端から少し内側に出るようになっています。画面が小さいと、出る範囲もせまくなります
- ホーム画面に追加しておくと、アドレスバーが消えて画面を広く使えます

## 記録について

**きろくは、その端末のブラウザの中だけに残ります。** サーバーには送っていません。
そのため次のことに気をつけてください。

- **端末を替えると引き継がれません。** iPadごとに別々のきろくになります
- ブラウザの履歴やサイトデータを消すと、きろくも一緒に消えます
- ホーム画面に追加して使うと、データが自動で消されにくくなります
- 500件をこえると、古いものから順に消えていきます

「ほぞん」を押さないかぎり、何も残りません。

## 動作環境

iPad / パソコンの新しめのブラウザ。インターネットにつながっていれば、そのまま開けます。

## 開発

Vite + React。

| | |
|---|---|
| `src/modes.js` | モードの設定（玉の大きさ・上下運動の有無・動く速さ）。`MODES` がメニューに出る3つ、`HIDDEN_MODES` がかくれモード |
| `src/Menu.jsx` | モードえらび画面 |
| `src/TouchPracticeSound.jsx` | 本体（音・波紋・玉・カウント・ほぞん） |
| `src/Records.jsx` | きろく一覧の画面 |
| `src/recordStore.js` | きろくの読み書き（localStorage） |
| `src/HoldButton.jsx` | 長押しで効く先生用ボタン |
| `src/App.jsx` | メニューと本体の切りかえ |

難易度を足したり調整したりするときは `src/modes.js` だけを触ればすみます。

```
npm install
npm run dev
```

main ブランチに push すると、GitHub Actions がビルドして
GitHub Pages に公開します（`.github/workflows/deploy.yml`）。
公開先が `https://eduwithdai.github.io/<リポジトリ名>/` の下になるため、
ワークフローが `BASE_PATH` を渡し、`vite.config.js` がそれを `base` に使っています。
